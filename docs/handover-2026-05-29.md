## 5. Wichtige Architektur-Entscheidungen aus dieser Session

- **Lokaler Ordner über File System Access API** statt zentrales Backend — funktioniert nur in Chromium (Safari/Firefox bleiben auf IndexedDB-only mit klarer Empfehlung zu Chromium).
- **Pseudonymisierung im KI-Prompt**: Schülername geht NICHT mehr an Anthropic. Beleg dafür in `app.html` rund um `examLabel` und `examText` (~Zeile 3115).
- **Sorgfaltsregel im KI-Prompt**: neues Feld `unsicher` pro (Teil-)Aufgabe; UI hebt sie gelb hervor. Pseudo-Codepfad: `kiKorrigieren` → `sorgfaltHinweis` im Prompt → `showKiErgebnis`/`buildKorrekturDocx` rendern Highlights.
- **12-Seiten-Regel** server-seitig durchgesetzt in `api/claude.js` (`PAGES_PER_UNIT = 12`); App schickt `pages` mit dem Request und zeigt einen Bestätigungs-Dialog bei >1 Einheit.
- **Drei Dokumenttypen pro Prüfung**: `vorlagenpruefung`, `musterloesung`, `material`. Schema-Migration nicht nötig (IndexedDB-schemalos); abwärtskompatibel über `ist_musterloesung`-Fallback.
